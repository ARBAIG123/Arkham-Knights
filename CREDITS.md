## Speech samples

`assets/voice/vo.js` embeds generated MP3 dialogue and character barks. The repository's [voice generation script](assets/voice/generate_voices.py) uses Microsoft's online Edge neural text-to-speech service through [`edge-tts`](https://github.com/rany2/edge-tts).

Distinct voice IDs configured by the script: `en-US-ChristopherNeural`, `en-US-GuyNeural`, `en-GB-ThomasNeural`, `en-US-AvaNeural`, `en-US-EricNeural`, `en-US-JennyNeural`, `en-AU-WilliamNeural`, `en-US-RogerNeural`, `en-US-BrianNeural`, `en-US-SteffanNeural`, and `en-GB-RyanNeural`.

**License status:** the repository does not include a standalone license or redistribution grant for the generated speech files. The [`edge-tts` library is LGPL-3.0](https://github.com/rany2/edge-tts/blob/master/LICENSE); that covers the library code, not Microsoft's generated voice output. Microsoft's [Azure TTS product terms](https://www.microsoft.com/licensing/terms/productoffering/MicrosoftAzure/EAEAS) describe output-use rights for paid-tier Azure customers, but this project records use of the separate Edge online endpoint and does not establish an applicable output license. Redistribution rights for these bundled voice samples are therefore **unverified**. See Microsoft's [text-to-speech transparency note](https://learn.microsoft.com/en-us/azure/foundry/responsible-ai/speech-service/text-to-speech/transparency-note) for service context.

## Project-created content

Per the team disclosure, Claude Opus 5.5 was used to create the game's original code and authored content. The game's score and sound effects are generated by project code (`score.js` and `assets/sfx/generate_sfx.py`); no third-party music or sound-effect sample library was found in the repository. The speech samples above are the identified third-party audio exception.
